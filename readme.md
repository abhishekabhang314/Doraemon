# Doraemon Fan Page

## 🌟 About the Project
This is a **Doraemon Fan Page** website created using **HTML, CSS, JavaScript, and Bootstrap**. The website showcases details about **Doraemon**, including character information, images, and animations to enhance user experience.

## 🎨 Features
- **Character Details**: Information about Doraemon and other main characters.
- **Bootstrap Design**: Responsive and mobile-friendly layout.
- **Animations on Scroll**: Smooth animations using JavaScript.
- **Interactive UI**: Engaging design with a modern look.

## 🛠️ Technologies Used
- **HTML5** - Structure of the website
- **CSS3** - Styling and layout
- **JavaScript** - Dynamic interactions and animations
- **Bootstrap** - Responsive framework for UI design
